# Banana PICO 4 + SO-ARM101 遥操作

## Windows 快速开始

1. 在 GitHub 项目页点 **Code → Download ZIP**，下载并解压项目。
2. 安装一次 [Python 3.12](https://www.python.org/downloads/)，安装时保留 Python Launcher（`py`）。
3. 双击要使用的启动脚本：

| 启动脚本 | 用途 |
|---|---|
| `PICO调试.cmd` | 电脑仿真，不连接或移动真机械臂。 |
| `PICO真机遥操作.cmd` | 启动真机遥操作；先接好控制板、电源、六个舵机和 PICO。 |

首次打开脚本会自动创建运行环境并安装依赖，等待安装完成即可；之后双击就能启动。无需手动复制或填写项目配置文件。若首次安装失败，检查网络后重新双击。

## 真机首次使用

在真机页面选择 LeRobot 导出的 SO101 标定 JSON，点击「导入标定文件」。确认机械臂固定、空载、工作区清空后，勾选工位确认并点击「按当前姿态接管电机」。戴上 PICO 进入透视：右手柄竖直、松开握持键和扳机，短按 A 记录参考；松开 A 后再短按一次授权。按住握持键操作，松开保持，按 B 停止。

需要手动摆动机械臂时，在电脑页面点击「一键下电（手动调整）」，确认六轴显示已下电后再调整；重新操作前再按「按当前姿态接管电机」。下电前托住机械臂，避免关节因重力下落。

PICO 自动连接需要 Android Platform Tools（`adb`）和头显中的 USB 调试授权；也可以在 PICO 浏览器打开页面显示的头显地址。仿真模式在头显点「VR 仿真预览」；真机模式点「进入透视遥操作」。导入不会启用电机。标定和自动生成的运行文件只保存在本机 `artifacts/pico-teleop`。

项目采用 MIT 许可；SO-ARM101 模型和 Feetech SDK 的许可见各自目录。
