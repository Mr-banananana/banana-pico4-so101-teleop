# 自动进入可达工作区

自动准备功能在获得新鲜关节反馈后，使用本机控制参考中的工作区和限位，规划到最近的可达位置。它只负责把当前姿态移到可操作区域，不授予 XR 手柄控制权。

- 控制目标与逆运动学约束采用内缩后的工作区，减少贴边运行。
- 规划器先验证到目标的路径，再按配置的速度和加速度执行；反馈稳定后才结束准备。
- 运行期间对手柄目标做工作区限幅，并保留边界上的切向移动与反向离开能力。
- 用户停止、反馈过期、供电或电机故障会优先中止自动准备。
- 所有尺寸均以米为单位；边界、内缩量和运动限制应按实际安装、标定与工位重新配置。

最近可达位置是基于关节限位和采样路径检查得到的局部解。它不等价于完整碰撞检测，也不能替代真实反馈和硬件保护。
