# 夹爪抓取与接触保持

夹爪支持扳机切换模式：扣动一次抓取，松开后保持；再次扣动张开。需要在本机控制参考中将 `gripper_mode` 设为 `toggle`。`analog` 模式则按扳机量控制开度。张开目标使用本机标定保存的中性位置。

接触保持根据位置反馈推断夹爪受到阻挡：连续的新鲜反馈在规定时间内变化很小时，控制器把闭合目标调整到接触位置附近，避免电机持续追逐无法到达的闭合目标。保持量和检测阈值需要按电机、夹爪结构和物体重新评估。

这不是测力传感器闭环，不能保证夹持力或物体承载能力。不得据此提高扭矩限制或绕过电机过流、温度、供电及反馈故障保护。实机调试应空载开始，并在工作区内验证。

电压异常处理应依据独立的新鲜测量确认；不能用历史正常读数覆盖当前异常。持续越界、复测失败或数据不一致时应保持故障状态。
